# Project Analysis: Weather App (Weatherly)

## Overview

This is a **feature-rich, real-time weather dashboard** built with React and Vite. It's called "Weatherly" (based on the logo in Header.jsx) and provides weather forecasts, severe weather alerts, and an immersive visual experience powered by the free [Open-Meteo API](https://open-meteo.com/) with no API key required.

## Core Features

### 1. Weather Functionality

- **City Search**: Autocomplete powered by Open-Meteo Geocoding API (8 results)
- **Current Conditions**: Temperature, feels-like, humidity, wind, pressure, cloud cover, UV index, visibility
- **24-Hour Forecast**: Scrollable horizontal forecast with precipitation probability
- **7-Day Forecast**: Daily highs/lows with temperature bar visualization
- **Sunrise/Sunset**: Animated SVG sun arc showing daylight progress
- **Geolocation**: "Use My Location" button with proper permission handling
- **Auto-Refresh**: Background refresh every 5 minutes when viewing weather
- **Unit Toggle**: Switch between Celsius and Fahrenheit

### 2. Themes & UI

- **Light/Dark/System Themes**: Three theme modes with CSS variables and localStorage persistence
- **Dynamic Backgrounds**: Animated weather backgrounds based on conditions (clear, cloudy, rain, thunderstorm, snow, night)
- **Glassmorphism Design**: Frosted glass cards with backdrop blur effects
- **Responsive Design**: Breakpoints at 380px, 640px, 900px, 1100px
- **Smooth Animations**: Framer Motion for page transitions and component animations
- **Loading States**: Skeleton UI during data fetches
- **Error Handling**: Graceful error states with retry functionality

### 3. Favorites & Personalization

- **Favorites System**: Save/remove cities with heart toggle
- **localStorage Persistence**: Favorites, theme, temperature unit preserved
- **Quick Access**: Favorites displayed as clickable chips in search and as cards below dashboard

### 4. Advanced Weather Alert System

This is a standout feature - a comprehensive alert monitoring system:

- **Real-Time Monitoring**: Checks weather conditions every 15 minutes
- **Multi-Point Radar**: Monitors a 9-point grid within configurable radius (5-50 km) - simulates radar sweep
- **Severity Levels**: Normal (🟢), Watch (🟡), Severe (🟠), Critical (🔴)
- **Alert Categories**: Thunderstorm, Heavy Rain, Strong Wind, Extreme Heat, Extreme Cold
- **Smart Detection**:
  - Thunderstorms: WMO codes 95, 96, 99 with escalation based on wind speed
  - Heavy Rain: WMO codes 63, 65, 67, 81, 82 with probability thresholds
  - Strong Wind: >30 km/h (Watch), >45 (Severe), >60 (Critical)
  - Extreme Heat: >37°C (Watch), >40°C (Severe), >45°C (Critical)
  - Extreme Cold: <0°C (Watch), < -10°C (Severe), < -20°C (Critical)
- **Deduplication**: Fingerprint-based system prevents duplicate notifications; escalations re-notify
- **Browser Notifications**: Native push notifications with permission handling
- **Alert Sound**: Web Audio API beeps (configurable)
- **Quiet Hours**: Only Critical alerts trigger during configured quiet hours (default 11 PM - 6 AM)
- **Alert History**: Stores last 20 alerts in localStorage
- **Alert UI Components**:
  - AlertBanner - Top-of-page alert for new alerts
  - AlertCenter - Slide-out panel with active alerts & history
  - AlertDetail - Detailed view of an alert
  - AlertSettings - Configure radius, categories, sounds, etc.
  - AlertRadar - Visual radar showing monitoring area
  - AlertToast - Toast notification for new alerts
  - AlertNotificationPrompt - Browser permission prompt
  - MonitorButton - Start/stop monitoring
  - MonitorStatus - Status indicator

### 5. Additional Features

- **Weather Mood**: Fun mood display based on weather
- **Share Card**: Generate shareable weather summary (functionality present)

## API Integration

The app uses Open-Meteo exclusively (no API keys):

1. **Geocoding API**: `geocoding-api.open-meteo.com/v1/search` - City search with autocomplete
2. **Forecast API**: `api.open-meteo.com/v1/forecast` - Current, hourly (24h), daily (7d) forecasts

Fields requested include temperature, weather code, humidity, wind speed/direction/gusts, pressure, cloud cover, UV index, visibility, precipitation, sunrise/sunset, etc.

## State Management

- **useWeather Hook**: Manages weather data, search results, favorites, theme, unit, auto-refresh timers, geolocation
- **useAlerts Hook**: Manages monitoring state, alerts, history, settings, notifications, timers
- **localStorage**: Persists user preferences and data
- **Refs**: Used for timers and to avoid stale closures in callbacks

## Potential Issues & Observations

1. **CSS File Size**: `App.css` is 1231 lines - could benefit from modularization (CSS modules, styled-components) but current approach works fine for this size
2. **No Tests**: `detected_test_files: 0` - no test files found. Would benefit from adding tests
3. **No TypeScript**: Written in JavaScript despite TypeScript types installed
4. **Alert Engine Complexity**: Multi-point monitoring makes 9 parallel API calls every 15 min - could be rate-limited by Open-Meteo but should be fine for personal use
5. **Browser API Dependencies**: Geolocation, Notifications, Web Audio - properly checks for availability
6. **Build Tool**: Uses modern Vite 8, should build without issues
